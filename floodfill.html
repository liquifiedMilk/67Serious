Flood Fill Algorithm

The Flood Fill algorithm models maze solving like water filling a network of trenches. Starting from an origin, it expands outward level by level into every accessible connected corridor. By tracking distance values across the grid (wavefront propagation), it guarantees discovering the shortest path to any reachable exit.

Every step in Flood Fill goes:

1. Pick earliest flooded point in queue
2. Check all unflooded adjacent corridors (North, East, South, West)
3a. If an adjacent cell is open and unflooded, fill it with distance + 1.
3b. If an adjacent cell is a wall, block flow in that direction.
3c. If all adjacent cells are flooded, move to the next queued point.
3d. If the flood reaches the finish, trace backwards down the distance gradient to complete.
