Pros & Cons Comparison

Algorithm Pros Cons
BFS
(Breadth-First Search)
  • Guarantees the shortest path
  • Always finds an exit if one exists
  • High memory consumption
  • Slow; explores blindly in every direction
DFS
(Depth-First Search)
  • Low memory consumption
  • Can reach the goal very quickly if lucky
  • Does not guarantee the shortest path
  • Can explore deep dead ends unnecessarily
A* Search
  • Guarantees the optimal shortest path
  • Explores far fewer cells using a heuristic
  • Requires an accurate heuristic function
  • Higher memory usage similar to BFS
Wall Follower
  • Zero map memory needed (only tracks current orientation)
  • Extremely simple rule-based implementation
  • Fails if start or goal is on an isolated island loop
  • Does not guarantee shortest path; can take very long detours
Flood Fill
  • Guarantees the shortest path
  • Reliably maps and solves any open area geometry
  • High memory and processing overhead
  • Explores blindly in all directions without heuristic direction
